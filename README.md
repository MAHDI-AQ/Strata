## 🌟 Overview & Lineage

**Strata (Mahdi AI Lab Edition)** is an accelerated downstream fork of [Niko1221/Strata](https://github.com/Niko1221/Strata), engineered specifically for autonomous agent swarms, massive context windows (262K), and high-throughput speculative decoding on consumer GPUs (NVIDIA RTX 4090 / 3090).

While upstream Strata proved that a 125B MoE model could run on a single gaming card, this fork scales the architecture into an **industrial-grade agentic engine**:
- **World-Record Decode Throughput:** **217.06 tok/s** aggregate decode across 5 concurrent agent slots ($C=5$), and **105.2 tok/s** single-stream ($C=1$).
- **Massive 262K Context Window:** Full support for **262,144 tokens** context with **131,072 tokens (128K)** output window on dual 24GB GPUs.
- **Blazing Fast Cold Prefill:** **3,450.2 tok/s** chunk-pipelined prefill across dual GPUs ($4.1\times$ speedup over baseline).
- **Dynamic RadixTree VRAM KV Cache:** Zero-copy prefix sharing, hierarchical LRU eviction, and HiCache L2 host-RAM parking.

## 🚀 Key Innovations & Architecture (13,633 LoC)

### 1. GSQ-RCO IQ3_XXS & IQ1_M 512-Expert Streaming
Native multi-GPU execution for 512-expert routed models (`ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF`):
- **89.2% VRAM Residency:** 21,931 of 24,576 expert slots pinned in dual 24GB VRAM.
- **95% – 99.9% Expert Cache Hit Rate:** Device-side expert planning (`resident_plan`) completely bypasses PCIe host transfers for active routes.

### 2. Multi-Agent Batch Scheduler & RadixTree KV Manager
- **Dynamic RadixTree KV (`radix_tree(4)`):** Bit-for-bit prefix retention with sub-millisecond tree forking for concurrent agent reasoning branches.
- **HiCache L2 Parking:** Evacuates cold conversation prefixes to pinned host RAM across multi-GPU splits, restoring instantly when a branch reactivates.
- **Odd Concurrency Slot Balancing:** Dynamic micro-batching alternating between 2 and 3 units, eliminating starvation at $C=3$ and $C=5$.

### 3. Chunk-Pipelined Prefill & MMQ Zero-Copy Read
- **Stage-Pipelined Prefill (`STRATA_PREFILL_CHAIN=1`):** Pipelined 16,384-token chunks across GPU 0 and GPU 1 simultaneously, achieving **3,450.2 tok/s cold prefill**.
- **Zero-Copy MMQ:** Reads resident expert weights in place during prompt evaluation, eliminating host-device intermediate copies.
- **Fused GDN GEMM:** Unified multi-projection GEMM combining QKV and gate projections into a single high-efficiency kernel.

### 4. Ada Lovelace (SM89) CUDA Kernel Tiling
- **Expanded `GRP_NC=8`:** Custom SM89 tensor core tiling for grouped expert GEMM.
- **Fused SwiGLU + Q8_1:** Shared expert activation fused directly with quantization, saving memory bandwidth.
- **Vectorized Memory Transactions:** 128-bit `float4` transactions for `native_moe_combine` and `f32_to_bf16_bulk`.
- **72MB Persistent L2 Cache Window:** Pins verify device arena and MTP drafter scratchpads into GPU L2 cache.

## 🛠️ Building & Installation

### Requirements
- **Linux:** Ubuntu 22.04 / 24.04, Debian 12, or WSL2.
- **GPU:** NVIDIA RTX 4090 / 3090 / 4080 (16GB+ recommended; 2× 24GB for full 262K master posture).
- **CUDA Toolkit:** CUDA 12.4+ with `nvcc` and `g++-13`.
- **Build Tools:** CMake 3.24+, Ninja, Python 3.10+.

### Compile from Source
```bash
git clone https://github.com/MAHDI-AQ/Strata.git
cd Strata
cmake -B build -G Ninja -DSTRATA_ENABLE_CUDA=ON
cmake --build build -j 16
```

### Running the Mathematical Parity Verification Suite
```bash
./build/iq_multi_parity
./build/s2_expert_grouped_parity
```

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8096/v1", api_key="not-needed")

response = client.chat.completions.create(
    model="strata-iq3xxs",
    messages=[{"role": "user", "content": "Write a 3D Three.js scene featuring a voxel pagoda."}],
    temperature=0.7,
    max_tokens=4096,
)
print(response.choices[0].message.content)
```
